# Reference data for the migration tests

These files pin the behaviour of the Python original that the C# port must reproduce.
They are test input, not configuration for the application.

| File | Meaning | Regenerated by |
| --- | --- | --- |
| `config-defaults.json` | Effective defaults of the Python configuration model | `archive: scripts/capture_migration_reference.py` |
| `python-config.example.yaml` | Copy of the Python `config.example.yaml`, frozen for the import test | copied by hand |
| `detection-golden.json` | Normalisation, similarity, detection and deduplication cases | `archive: scripts/capture_detection_reference.py` |
| `change-detection-golden.json` | Change-detection ratios; the crops are described by formula | `archive: scripts/capture_change_detection_reference.py` |
| `reports-baseline/` | events.json, events.csv, segments.json and summary.json of one Python run | copied from a Python analysis run |

The capture scripts belong to the Python reference project and are never part of the
C# build, the published application or a test run.
